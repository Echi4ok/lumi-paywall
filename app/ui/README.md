# Небольшой UI-слой

Здесь только элементы, которые повторяются в сценарии. Выбор тарифа, квитанция, цены и состояние покупки остаются в `features/paywall`.

| Компонент   | Контракт                                                                                | Проверяемые состояния                                                                                              |
| ----------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `UiButton`  | `variant`: primary / secondary / ghost; `disabled`; `loading`; default и trailing slots | Нативный фокус, клик, запрет действий при disabled/loading, `aria-busy`, скрытие декоративной стрелки при загрузке |
| `UiSpinner` | Декоративный индикатор, наследует цвет текста                                           | Не дублирует голосовое объявление; анимация отключается общим `prefers-reduced-motion`                             |
| `UiMessage` | `tone`: info / error; необязательный `title`; default и actions slots                   | `role=status` для информации, `role=alert` для ошибки; inline и panel расположение                                 |

Токены находятся в `app/assets/css/tokens.css`, сбросы и базовая типографика — в `base.css`. UI и feature стили лежат рядом с компонентами и подключаются через scoped CSS; внешние отступы задаёт feature.

Каталог состояний выполняется в `tests/components/ui.test.ts` и `tests/components/paywall.test.ts`: `npm test -- tests/components`. Это настоящие Vue-компоненты в Happy DOM, со штатным `usePaywall` и подменой только HTTP-порта. Проверяются radio change, loading, ошибки, пустой каталог, восстановление без каталога, истёкший повтор и фокус успеха. Отдельный showcase маршрут и Storybook не поставляются в приложение.

Палитра учитывает минимальный контраст: вторичный текст `#726580` на выбранной карточке `#F0E9FF` — **4.58:1**; граница невыбранного radio `#9385A5` на белом — **3.42:1**. Эти числа — расчёт WCAG относительной яркости; реальные браузерные сценарии проверяются отдельно.
