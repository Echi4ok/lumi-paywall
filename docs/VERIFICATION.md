# Проверка результата

13 октября 2026 года. Проверки выполнены Codex через CLI, независимых агентов и браузер. Ручное тестирование человеком не заявляется.

## Код и архитектура

- `npm run check`: форматирование, ESLint без предупреждений, TypeScript, **53 теста** — 39 серверных и 14 клиентских.
- `npm run build`: production-сборка Nuxt/Nitro проходит. Vercel также собрал и запустил приложение.
- [Независимое ревью](REVIEW.md): пять подтверждённых замечаний исправлены, регрессии покрыты тестами и повторно просмотрены.
- Тестируются строгая валидация, ограничения JSON, cookie, Origin, ошибки БД, SQL-ограничения, срок доступа, повтор покупки, отмена и дедлайн запросов, сохранение выбранного тарифа и ключа незавершённой попытки.

## Реальный сервер и хранение

`npm run smoke -- https://lumi-paywall.vercel.app` проходит: каталог, новая сессия, пустое восстановление, покупка, повтор, восстановление, конфликт тарифов, неверный запрос и изоляция устройств. **12 одновременных HTTP-запросов** с одним ключом возвращают одну покупку; прямой SQL-запрос к Neon подтвердил ровно одну строку для этой попытки.

В браузере оформлен месячный доступ, затем страница полностью перезагружена. «Восстановить покупки» вернул тот же UUID покупки и прежние даты. Дополнительно проверен локальный запуск без `DATABASE_URL`: PGlite создал `.data/lumi`, а после остановки и нового запуска Nuxt восстановил покупку с тем же ID и датами. Миграция общая для обоих драйверов.

## Браузер и макет

- Chrome: ширины **360, 390 и 430 px**, без горизонтальной прокрутки. Основная кнопка 56 px, восстановление 44 px. Radio-кнопки переключаются стрелками с клавиатуры.
- Покупка и восстановление, пустой результат восстановления, блокировка повторного нажатия во время запроса, перевод фокуса на заголовок успеха.
- Отключение сети через DevTools во время покупки показывает понятную ошибку. После восстановления сети повтор завершает покупку успешно. В обычном сценарии ошибок и предупреждений в консоли нет; искусственно отключённая сеть ожидаемо даёт сетевую ошибку.
- [Редактируемый Figma](https://www.figma.com/design/UXGo2MuLLvDZEtRs3Giisd?node-id=2-2) содержит основной экран, загрузку, ошибку и успех. В окне Share проверен доступ **Anyone can view**.
- Экспорты Figma и снимки браузера находятся в [design](../design/README.md). Сверены размеры, цвета, шрифт, отступы и оригинальный SVG. После сравнения исправлены смещения текста карточек на 1–2 px.

Для двух изображений 390 × 838 (`figma-390.png`, `browser-390.png`) среднее абсолютное отклонение RGB равно **2.659 из 255**; нормированное сходство `100 × (1 − MAE / 255)` — **98.96%**, то есть около 99%. Это прозрачная численная оценка всего изображения, **не доля полностью одинаковых пикселей**: Figma и Chrome по-разному сглаживают шрифты. При допуске 16 на канал совпадают 94.15% пикселей. Изображения сохранены для независимого визуального сравнения; геометрия проверялась отдельно.

## Ограничения

- Физические iPhone/Android и встроенные WKWebView/Android WebView не проверялись. Эмуляция размеров Chrome не заменяет эту проверку.
- Восстановление относится к этому браузеру и cookie. После её удаления или на другом устройстве без аккаунта восстановить доступ нельзя.
- Платёжного SDK, реального списания и автопродления нет. Данные — учебные покупки; серверная БД используется по назначению задания.
- `npm audit` на дату проверки: 0 critical, 11 high с учётом транзитивных цепочек. Два исходных advisory относятся к `braces` (обработка glob) и `node-forge` (dev TLS) внутри инструментов Nuxt; эти пакеты отсутствуют в manifest собранного Nitro server. Исправлены доступные критические проблемы обновлением Vitest и override `simple-git`. Оставшиеся цепочки зафиксированы, а не скрыты принудительным downgrade Nuxt; перед расширением проекта следует обновить исправленные upstream-версии. Это не заявление об отсутствии всех уязвимостей production.

Ближайшее продолжение: реальный webview, проверка рендера на устройстве, ограничение частоты запросов перед более широкой демонстрацией. Эти пункты отделены от подтверждённых выше результатов.
